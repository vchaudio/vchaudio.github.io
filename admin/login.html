Sign in

Authenticate with a GitHub Personal Access Token. Content is read from and written to your repository via the GitHub Contents API — changes go live on GitHub Pages after the next build.

The token is stored only in your browser (localStorage if remembered) and sent directly to GitHub. Use a fine-grained PAT scoped to this repository with Contents: Read & Write.

How to create a token
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it “VCHAudio admin”, set an expiration.
  3. Repository access → Only select repositories → choose this repo.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate and paste the token above.
